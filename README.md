# Monitor program de guvernare 2026-2028

Pagina publică: https://silviucosa.github.io/monitor-program-guvernare

- `index.html` — pagina
- `data/masuri.json` — toate măsurile programului, clasificate (termen, cifră)
- `data/angajamente.json` — angajamentele datate urmărite, cu status
- `data/verificare_200.json` — cele 200 de măsuri fără termen și fără cifră, cu cel mai avansat pas găsit (sursa cifrelor din cardul „verificare”)
- `data/meta.json` — data ultimei actualizări

Statusuri folosite: de urmărit, în curs, îndeplinit, parțial, neîndeplinit, termen depășit, ratat, amânat, de verificat. „Termen depășit”: termenul a trecut fără realizare confirmată; „neîndeplinit”: niciun pas de fond (comitetele, grupurile de lucru și calendarele nu contează); „ratat” doar când o sursă confirmă că nu se mai realizează.
