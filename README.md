# Monitor program de guvernare 2026-2028

Pagina publică: https://silviucosa.github.io/monitor-program-guvernare

- `index.html` — pagina
- `data/masuri.json` — toate măsurile programului, clasificate (termen, cifră)
- `data/angajamente.json` — angajamentele datate urmărite, cu status
- `data/meta.json` — data ultimei actualizări

Statusuri folosite: de urmărit, în curs, îndeplinit, parțial, ratat, amânat, de verificat.
